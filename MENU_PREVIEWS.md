# Разработка: меню SUNPARK

Для администраторов: /admin → «🛠 Разработка» → «🌿 Меню SUNPARK». В разделе оставлено только текущее фирменное Mini App с корзиной, оформленное в стиле печатного PDF. Старые кнопки вариантов из сообщений ведут в этот же раздел.

Меню показывает кухню, напитки и бар; состав открывается по нажатию на блюдо. Крупные разделы и кнопки целиком видны на узком экране. Открытая карточка закреплена в окне: фон не прокручивается, длинный состав прокручивается внутри, после закрытия восстанавливается прежняя позиция списка. Названия, составы и цены берутся из действующего config.menu. Банкетный каталог не включается.

## Корзина Mini App

- Добавление из карточки блюда; для двух цен сначала нужно выбрать объём или вариант. Вино — бокал/бутылка, Эль Капулько — алкогольное/безалкогольное, Бенедикт — форель/ростбиф. Неопознанные варианты сохраняют обе цены и явный выбор.
- Внизу меню — кнопка с количеством и полной суммой. Корзина открывается отдельным экраном; позиции идут одним списком, каждая занимает одну строку. Нажатие открывает полный текст, количество и удаление. Очистка всей корзины требует подтверждения.
- Суммы считаются целыми копейками. Неизвестная или зависимая от веса цена помечается как требующая уточнения и не превращается в ноль.
- Черновик хранится в localStorage этого устройства отдельно для каждого Telegram ID. В нём только ссылки на позиции, варианты и количества. При открытии позиции и цены сверяются с актуальным каталогом: удалённые позиции отбрасываются, новые цены используются автоматически. Серверная база и старая гостевая корзина не меняются.
- Это подсчёт суммы для показа официанту: отправка заказа, оплата и уведомления сотрудникам не выполняются. Доступ к Mini App по-прежнему только у администраторов.

## Доступ

Все callback-кнопки с префиксом mp: требуют актуальных прав менеджера и личного чата. Простое копирование кнопки не даёт доступа.

Mini App отдаёт публично только пустую оболочку HTML/CSS/JS. POST /api/menu-preview проверяет Telegram.WebApp.initData: HMAC-SHA-256, auth_date не старше часа и Telegram ID из подписанного user. После этого проверяется действующий список менеджеров. Переданный отдельно user_id не используется. Гостю с корректной подписью возвращается 403, без подписи — 401. Ответ не содержит config, профили, телефоны или регистрации мероприятий. Размер тела ограничен при чтении потока; ответы не кешируются. Секрет бота не попадает в браузер или URL.

## Файлы

- src/menu_preview.py — раздел «Разработка», каталог, варианты цен, авторизация и HTTP-маршруты;
- ui/menu_preview/index.html, style.css, app.js — исходники Mini App;
- ui/menu_preview/sunpark-logo.svg — исходные векторные контуры логотипа из PDF;
- ui/menu_preview/botanical-pattern.webp — растительный рисунок из PDF, подготовленный для мобильного фона;
- src/menu_preview_assets.py — те же статические ресурсы в Python-строках для доставки модульным Python Worker;
- tests/test_menu_preview.py — подписи, доступ, пагинация, безопасный вывод и fallback;
- tests/browser_scroll_check.py — прокрутка открытой карточки мышью и касаниями, длинный состав, изменение высоты окна и восстановление позиции при закрытии;
- tests/browser_cart_check.py — сценарии добавления, выбора варианта, суммы, изменения количества, удаления, сохранения, 20 позиций и смены аккаунта;
- tests/browser_preview_check.py — проверка двух оформлений в Chromium на ширине 320, 390 и 820 px с проверкой навигации, размеров кнопок, читаемости цен, поиска и возврата. Только локальный тест использует фиктивный токен и тестовую подпись, в рабочем боте обхода авторизации нет.

Новых production-зависимостей нет. После изменения HTML/CSS/JS выполните сборку ресурсов. Обычные проверки проекта:

```sh
python scripts/build_menu_preview_assets.py
PYTHONPATH=src python -m unittest discover -s tests -v
node --check ui/menu_preview/app.js
```

Для локальной проверки интерфейса дополнительно нужны Playwright и Chromium:

```sh
python -m pip install playwright
PYTHONPATH=src python tests/browser_preview_check.py
PYTHONPATH=src:tests python tests/browser_cart_check.py
PYTHONPATH=src:tests python tests/browser_scroll_check.py
```

Логотип отдаётся по /menu-preview-logo.svg. Растительный фон упакован сборщиком в CSS как data URL, без внешних сервисов и загрузки полного PDF. Раздел «Разработка» запускает только фирменное оформление (variant=4). Старые вспомогательные шаблоны не предлагаются в интерфейсе.

В модуль Worker должны входить entry.py, events.py, validation.py, menu_preview.py и menu_preview_assets.py вместе с существующим SDK. Действующие настройки, привязки, база и секреты сохраняются. Доступ к разделу для гостей не открывается.
