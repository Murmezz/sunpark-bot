# Assets

- SUNPARK logo: original supplied restaurant PDF, reused from the existing menu.
- Monstera: generated with OpenAI ImageGen for this selected design; transparent WebP encoding of the generated asset. Source: `/workspace/generated_images/exec-58b3eb65-0fc4-465e-929a-29d201b0e581.png`.
- Cormorant Garamond and Manrope: Google Fonts, local WOFF2 Latin/Cyrillic subsets and a Cormorant Garamond 600 TTF numeral subset. SIL Open Font License; license texts alongside these files.
- Icons: official `@phosphor-icons/core@2.1.1` regular SVGs, MIT license (`LICENSE-Phosphor.txt`). https://phosphoricons.com/

Fonts and raster imagery are bundled locally; runtime requests do not depend on a font or image CDN.
